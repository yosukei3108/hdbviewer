# Change Log

All notable changes to the "hdbviewer" extension will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/).

## [Unreleased]

## [0.0.2] - 2026-10-02

### Changed

- Rename the display name to "Tokyo Cabinet HDB Viewer".
- Add Marketplace categories and keywords.

## [0.0.1] - 2026-10-02

### Added

- Open `*.tch` / `*.hdb` files in a read-only table view.
- Show DB info from `tchmgr inform`.
- Paging with the `hdbviewer.recordsPerPage` setting.
- Filter records by key prefix (`tchmgr list -fm`).
- Search text in the keys and values on the current page.
- Reload the current page.
